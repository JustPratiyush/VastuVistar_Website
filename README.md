# VastuVistar Website

## About the Project

VastuVistar is a professional website designed to provide Vastu Shastra consultation services. The website offers expert guidance in transforming living and working spaces through ancient Indian architectural science principles.

## Features

- Modern and responsive design
- Professional consultation booking system
- Comprehensive Vastu Shastra information
- Client testimonials and reviews
- FAQ section
- Easy navigation and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Font Awesome for icons
